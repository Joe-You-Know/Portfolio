# Featured engineering

A small set of engineering projects chosen for implementation depth and the quality of the evidence, rather than the breadth of the claims.

| Featured project | Problem | Evidence | Study |
| --- | --- | --- | --- |
| CausalArt | Make desktop graphics actions measurable, reversible, and correctable | Krita/Blender runs, native editable saves, screenshot | [Open](causalart.md) |
| ConstructiveRT | Reliably observe and execute file/network transfers | C++20 tests, Windows WAN benchmarks, Linux build | [Open](constructivert.md) |
| CausalGPT / Eligens | Acquire and review information without treating a model's output as truth | Durable report, source-review controls, feedback contracts | [Open](causalgpt.md) |
