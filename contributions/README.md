# Accepted external open-source contributions

Pull requests below were merged into independently maintained public repositories. They are not forks merely created under my account, and the merge is verifiable from the linked upstream pull-request records.

## CloudCertPrep — accessibility

**[Fix MockExam question grid accessibility labels — PR #50](https://github.com/nastaso/cloudcertprep/pull/50)**  
**Merged:** June 16, 2026.

Updated stateful `aria-label`s for mock-exam question-grid cells, added `aria-current` for the active question, and hid a redundant decorative flag icon from assistive technology. The submission reported `npm run lint` and `npm test`. This is a focused web accessibility change, not a claim of creating the full CloudCertPrep product.

## EDDI — enterprise AI software documentation

**[Update lifecycle task type names — PR #554](https://github.com/labsai/EDDI/pull/554)**  
**Merged:** July 22, 2026.

Updated Java API/lifecycle documentation and interface notes to use the current `API Calls` and `LLM` labels while preserving historical changelog terminology. The submission reported successful local `./mvnw.cmd -DskipTests compile` with JDK 25.0.3. This is a documentation and terminology contribution, not ownership of the underlying EDDI platform.

## Evidence standard

A merged upstream pull request establishes that maintainers accepted a particular contribution. It does not by itself establish subsequent production usage, every downstream effect, or ownership of an upstream project.
