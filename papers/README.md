# Selected papers

This is a small, curated set of research manuscripts. Their arguments and conclusions are the author's; inclusion here does not imply peer review or independent proof verification. Software checks and numerical experiments are described separately where available.

1. **[Primitive Constructive Logic — Constraint-Rank Foundations Revision v1.4](primitive-constructive-logic-v1.4.pdf)** (October 11, 2026). The current manuscript in the PCL foundations series develops a dependency-ordered account of distinction, report, constraint rank, count, ratio, quotient and remainder, and coordinate compilation. It is a broad foundations manuscript; readers can start with its abstract and opening principles. The v1.4 manuscript version is separate from the v1.9 exact-algebra software package described in the [PCL case study](../case-studies/exact-algebra.md).
2. **[The Primitive Measure Theorem: Constructive Measure and Minimal Simplex Closure](primitive-measure-theorem-2026.pdf)** (revised June 11, 2026). This shorter paper argues a conditional claim: if a finite vertex-defined primitive must itself contribute positive measure in its dimension, the minimal closed form is an n-simplex. It explicitly limits that claim and does not reject calculus, measure theory, or coordinate methods.

These are the selected revisions for this portfolio, rather than an archive of every draft.
