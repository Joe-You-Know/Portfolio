This repository is the public home for selected project case studies. Each one separates what I built from what I tested and what remains open.

## How I work

I start with a measurable question, build an inspectable implementation, and record the conditions under which it was checked. I distinguish an automated test, a saved experiment, and independent validation because they answer different questions.
