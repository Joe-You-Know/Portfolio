# Portfolio

A professional portfolio for Joey Fredrickson, built to make selected work easy for employers and collaborators to find and evaluate.

This repository is dedicated to the portfolio website and its supporting content. It will feature concise project case studies, links to inspectable work, and clear descriptions of what was actually built and verified.

The site and case studies are being prepared. Research results will be described with their validation limits, and only material approved for public sharing will be published here.
