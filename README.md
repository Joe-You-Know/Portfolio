## Evidence policy

A successful test establishes behavior only under its recorded inputs, environment, and assertions. A saved result is not the same thing as an independently repeated run. A theoretical proposal is not an experimentally established physical or mathematical result. I keep the negative outcomes and unresolved boundaries visible.

Some active research source repositories are **private**. Public pages here provide bounded descriptions, selected evidence, and stand-alone examples where available; they do **not** imply that the full private code or source data is public. The [CIM](https://github.com/Joe-You-Know/CIM) and [CausalGPT](https://github.com/Joe-You-Know/CausalGPT) repositories currently require authorized access. The dedicated ConstructiveRT repository has not yet been published.
